# Almost Linked

A tiny, no-fail word-connection game made for big, unnecessary victories. Type any word and it instantly connects the two starter words—first try, every time.

This is an unofficial, independently made parody. It does not use assets, source code, or branding from other games.

## Run locally

Open `index.html` in a browser. The game is a static site with no build step or dependencies.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and publish from the `main` branch, using the root (`/`) folder.
